# LILiS graphic resources

*[Versione italiana](LEGGIMI.md)*

A collection of LILiS graphic resources and 3D models, free to use and redistribute under the terms of the **GNU GPL v3** license (see [LICENSE](LICENSE)).

## Contents

### `svg/`

- `logo_lilis.svg`: LILiS logo in vector format (Inkscape)

### `3d/`

- `lilis.blend`: Blender model of the LILiS logo
- `tux3.blend`: Blender model of Tux
- `tux3.stl`: Tux model exported to STL, ready for slicing and 3D printing
